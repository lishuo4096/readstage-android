# 0.2.1 阅读菜单与自动切章修复

## 单击菜单检查

单击正文现在交替显示、隐藏上下阅读菜单，仍保留 5 秒自动隐藏、长按听读与链接点击行为。Android 15 上连续点击多次，验证显示与隐藏均可正常切换。

## 阅读进度显示检查

永久隐藏旧阅读器顶部蓝色横向进度条，保留右侧原生滚动指示。底部的章节切换滑块和听读圆环功能不变。菜单显示与隐藏两种状态都检查了顶部进度条不可见。

## 章末自动续播检查

修复同一文件通过系统文件选择器与工作区打开时，URI 形式不同导致无法匹配章节的问题。章节列表按当前文件的同级目录确定，并保留播放目录快照，避免浏览其他工作区改变正在播放书籍的续播目标。

目录尚未返回时保留章末请求并等待加载；找不到当前章时给出提示。原生章末通知增加重发与执行确认，避免一次性消息在界面未就绪时丢失；同一播放会话的完成消息只执行一次。

自动进入下一章会从首句开始，不恢复该章以前保存的听读位置。导演模式缺少下一章方案时先分析，再启动听读；空白／无可朗读文本的章节会继续跳到后续章节。手动停止或切换文档会使待处理的续播请求失效。

Android 15 / API 35 实测：

- 普通听读：在首页状态下连续自动播放完三章，两次切章无遗漏、无重复。
- 导演模式：同样连续播放完三章，下一章新方案生成后继续播放。
- 各章实际启动均为片段索引 0；预先设置第二章旧进度也未影响自动从头播放。
- 核心自动测试共 8 项通过，新增 URI 匹配、同级章节目录测试。

证据：`evidence/reader-v021.json`、`evidence/reader-v021-director.json`。这些是有限的模拟器测试，不代表所有厂商后台策略或网络状态下都不会中断；API 失败仍会按现有重试及错误提示机制处理。

版本号 0.2.1，versionCode=4，沿用原调试签名，可覆盖安装并保留配置和已有进度。
