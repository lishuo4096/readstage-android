# 墨声，让文字有声音

Markdown 工作区 · 角色听读 · AI 导演

## 从这里开始

1. 回到工作区，选择一个文件夹，授权读取和写入。
2. 点击文件阅读，使用「编辑」修改并保存。切换文件会分别保留位置。
3. 在「听读设置」填写服务 API Key。密钥使用 Android Keystore 加密保存。
4. 选择音色，填写语气，先试听，再开始听读。
5. 开启 AI 导演，配置文本模型，点击「分析全文」。文本会发送到你配置的服务。
