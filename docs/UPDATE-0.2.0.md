# 0.2.0 阅读器重构

## 启播和 API 错误

首句就绪立即播放，后续仍以六槽窗口、两路并发补充缓存，不再等待五段全部生成。临时网络错误、HTTP 429、5xx 最多自动重试两次，间隔 1 秒、2 秒；每次重试显示提示。400、401、403 等请求或权限错误直接返回。连接超时 8 秒，语音读取超时 20 秒，文本模型读取超时 60 秒。预生成失败会提前显示实际 API 错误，而非到该句才无提示等待。

## 高亮、跟随与长按

按句号、问号、感叹号等分句，将当前句映射回渲染正文，保留粗体、链接等行内样式，以柔黄色背景标记。代码、公式和图表不参与朗读。正文自动滚动跟随当前句；手动触摸滚动、滚轮、翻页键操作暂停跟随 8 秒，空闲后恢复。长按正文约 550 毫秒显示「从此处开始听读」。

因分句规则变化，旧版本的段落进度和导演方案会失效，需要重新定位或分析，原文件和 API 配置保留。

## 持续播放与浮窗

原生播放服务迁移到独立 Android 进程 `cn.readstage.app:reader`，由 IPC 传递播放、暂停、下一句预备和状态；使用会话编号隔离过期消息。进入导演、设置、编辑页面或首页书架，不销毁听读会话。更改听读配置、音色、跳转位置或换章节会主动更新会话。

应用内圆形浮窗可拖动并记住位置，中心显示识别章节，圆环显示当前章内听读进度；点击返回正文。没有申请其他 App 上层悬浮权限，浮窗仅显示在墨声内。

独立播放进程不表示强杀后保证整本继续：云端预生成与调度仍由应用控制，系统强制结束、断网或厂商省电策略可影响后续请求；支持恢复最近保存进度。

## 书架与阅读界面

首页显示已授权文件夹卡片，点击进入后列出文件及子目录。目录按文件名／正文开头检测到的「第 XX 章／节／回／卷」排序，支持中文和阿拉伯数字，未识别章节时按自然文件名排序。授权撤销时提示重新选择。

阅读器底部四项依次为目录、日间／夜间、听读、设置；上方为上一章、章节进度条和下一章。目录展示工作区章节；播放结束自动进入下一章。5 秒没有操作时上下控制栏隐藏，点击正文唤回。手动拖动章节滑块时不会被状态刷新抢回。

## 验证

Android 15 / API 35 / emulator-5582，沿用原签名，versionCode=3。

- 核心自动测试 7 项通过：章节数值排序、逐句范围、导演补齐、队列边界与取消、协议结构等。
- 设备交互验证：首页文件夹层级、进入工作区、句子映射、首句立即播放、柔黄高亮、导演与首页不中断、圆环浮窗、控制栏隐藏／唤回、长按入口、手动滚动暂缓与恢复跟随。
- 真实 MiMo 请求验证：首播时后续缓存为 0–1 段，未等待五段；错误模型 HTTP 400 约 0.1 秒内返回。
- `adb shell ps -A` 确认 UI 主进程与 `:reader` 独立播放进程同时存在。

证据：`evidence/reader-v020.json`。重试策略已实现；未人为制造服务器限流或真实 5xx 故障。尚未覆盖所有厂商真机省电策略。
